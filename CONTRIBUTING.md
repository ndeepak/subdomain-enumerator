# Contributing

Contributions are welcome.

## Project goals

This project is intentionally small and focused on passive, low-noise subdomain discovery.

Please keep changes aligned with the project goals:

- simple and readable Python
- passive discovery only
- clear output and validation
- responsible, authorized use only

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Keep changes scoped and well documented.
4. Add or update tests for behavior changes.
5. Run the test suite before opening a pull request.

## Testing

```bash
python -m pytest -q
```

## Responsible use

This repository is for authorized security testing and research only. Do not use the project against targets you do not own or do not have explicit permission to test.
