# Security Policy

## Supported versions

This project is currently in active development. Please treat it as a small open-source utility and report issues responsibly.

## Reporting a vulnerability

If you discover a security issue, please do not open a public issue with exploit details.

Instead, contact the maintainer privately through the repository’s contact method or by opening a private security advisory if available.

Please provide:

- a clear description of the issue
- affected version or commit
- reproduction steps if possible
- impact assessment

We will review and respond as quickly as possible.
